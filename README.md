**Intro**

This web app is titled News Explorer, which allows users to search for news articles based on keywords and save them to their profile page.

**Functionality**

This page is connected to News API, which pulls in recent articles based on users search queries. Users can register and sign in, and upon sign-in they can save articles to their personal page. The saved articles page houses any articles that they have saved.

**Technologies & Techniques**

- CSS
  - CSS was leveraged for styling of all elements.
  - Media Queries used for responsive mobile design.
- BEM
  - File structure and class names are laid out in adherence with BEM recommendations.
- JavaScript/React
  - Leverages JSX instead of standard HTML
  - Code is organized in componenets for reusability
  - Manage state with React hooks to track and respond to data changes in the UI without manually updating the DOM
- Vite
  - Bundling/building
- API connection
  - Connected to https://newsapi.org/v2/everything API to dynamically pull in news articles based on keyword queries
